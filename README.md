### Featured Projects

#### [Pneumonia Detection](https://github.com/KaranP315/Pneumonia-detection)
Deep learning system for detecting pneumonia from chest X-rays using a custom CNN and EfficientNetB0, with Grad-CAM explainability and a Streamlit interface.

#### [Crop Recommendation System](https://github.com/KaranP315/Crop-Reccomendation-System)
Machine learning system that recommends suitable crops using soil nutrients and environmental factors through a Flask backend and Streamlit frontend.

#### [ASD-Diffusion](https://github.com/KaranP315/ASD-Diffusion)
Unsupervised anomalous sound detection system based on a diffusion model for machine condition monitoring, with a Gradio interface for audio-based inference.

#### [Network Intrusion Detection](https://github.com/KaranP315/Network-Intrusion-Detection)
Machine learning and ensemble-based intrusion detection project using NSL-KDD data to classify network traffic as normal or malicious.

#### [TrainConsistManagementApp](https://github.com/KaranP315/TrainConsistManagementApp)
Java-based train consist management application that models railway operations through structured use cases such as cargo handling, search workflows, exception handling, and performance comparison using loops versus streams.
